sequenceDiagram
    autonumber
    participant User as 用户
    participant App as 应用服务
    participant Redis
    participant MQ as MQ(Publisher Confirm)
    participant Consumer as MQ消费者
    participant MySQL
    participant Timer as 30s定时任务
    participant Compensate as 补偿任务

    Note over User,Compensate: 链路1：秒杀下单
    User->>App: 获取token
    User->>App: 秒杀下单请求
    App->>Redis: Lua脚本预扣：库存-1，限购+1，标记CREATING
    Redis-->>App: Lua执行结果
    alt Lua执行成功
        App->>Redis: ZADD seckill:creating 订单信息
        App->>MQ: 发送消息(开启Publisher Confirm)
        MQ-->>App: Publisher Confirm确认
        App-->>User: 返回orderNo，状态CREATING
    else Lua执行失败
        App->>Redis: 回滚Redis数据
        App-->>User: 返回下单失败
    end

    Note over User,Compensate: 链路2：MQ消费落库
    MQ->>Consumer: 消费订单消息
    Consumer->>MySQL: 查询orderNo做幂等校验
    alt 幂等校验通过
        Consumer->>MySQL: 开启事务：扣减库存 + 插入订单(UNPAID)
        MySQL-->>Consumer: 事务提交成功
        Consumer->>Redis: 更新状态 CREATING → UNPAID
        Consumer->>Redis: ZREM seckill:creating
        Consumer->>MQ: 手动ACK
    end

    Note over User,Compensate: 链路3：超时关闭 + 库存回补
    Timer->>MySQL: 扫描UNPAID订单，pay_deadline < 当前时间
    MySQL-->>Timer: 查出超时订单
    Timer->>MySQL: CAS更新订单状态 CLOSED_TIMEOUT
    Timer->>MySQL: 创建stock_compensation补偿记录
    Timer->>Compensate: 触发库存补偿任务
    Compensate->>Redis: 库存+1，限购-1
    Compensate->>MySQL: 库存+1
    alt 补偿成功
        Compensate-->>Timer: 补偿状态SUCCESS
    else 补偿失败
        Compensate-->>Timer: 补偿失败，自动重试
        Note over Compensate: 超过重试次数触发告警
    end
